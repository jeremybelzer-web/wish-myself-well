# Curiosities

Storyboard app for building a scene from measurable choices, and for studying a movie, a TV hour, or a game as those choices.

Open `index.html` for the current board. Claude should start at `CLAUDE.md`. The repo is https://github.com/jeremybelzer-web/wish-myself-well and the app is `apps/curiosities/`. Read `HANDOFF.md` before changing the app. Rows in `CURIOSITIES-REVIEW.md` are marked keep until Jeremy changes one to drop.

This folder is separate from `web/`. The app chat stays here.
