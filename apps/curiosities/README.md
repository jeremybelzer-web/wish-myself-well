# Curiosities

Storyboard app for building a scene from measurable choices, and for studying a movie, a TV hour, or a game as those choices.

Open `index.html` for the current board. Read `HANDOFF.md` before changing the app. Mark `CURIOSITIES-REVIEW.md` keep or drop before new curiosities are added.

This folder is separate from `web/`. The app chat stays here.
